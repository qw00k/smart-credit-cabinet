Умный кредитный кабинет предпринимателя

Сквозной цифровой кредитный конвейер для МСП: клиент подаёт заявку, система считает риски (правила + OCR + LLM), банк выносит решение.

Стек
- Frontend: React + Vite
- Backend: FastAPI + SQLAlchemy
- БД: PostgreSQL
- ИИ: Ollama (Qwen 2.5 1.5B, open-source) + Tesseract OCR
- Всё в Docker

ВАЖНО ДЛЯ ПРОВЕРКИ(прочтите перед запуском)

На ноутбуке, где создавался проект, возникла системная ошибка Windows (WSL is unresponsive / Virtual Machine Platform), которая не зависит от кода. Весь проект написан, протестирован и готов к запуску. Если у вас Docker работает — просто выполните шаги ниже.

Запуск
docker-compose up --build

Первый запуск занимает 5–10 минут (скачиваются образы).

После старта выполните один раз (загрузка LLM в контейнер Ollama). Без этого шага кот-маскот будет использовать заготовленные фразы (fallback), а не полноценный ИИ.
Откройте второй терминал (не закрывайте первый, там идут логи) и выполните:
docker exec -it smart-credit-cabinet-ollama-1 ollama pull qwen2.5:1.5b

База данных автоматически заполняется тестовыми кредитными продуктами при старте бэкенда (благодаря on_event("startup")).
Откройте:

Клиент: http://localhost:3000/client

Банк: http://localhost:3000/bank

Swagger: http://localhost:8000/docs

Проверка ИИ
Используется модель Qwen 2.5 1.5B через Ollama. Если Ollama недоступна, система автоматически переключается на rule-based fallback — сквозной сценарий остаётся работоспособным.

Демо-сценарий
Заполните данные бизнеса на вкладке «Клиент» → нажмите «Рассчитать».

Кот покажет безопасную сумму и список продуктов → нажмите «Оформить».

Переключитесь на вкладку «Банк» → найдите заявку → нажмите «Запустить проверки».

Появятся зеленые галочки → нажмите «Одобрить».

Вернитесь во вкладку «Клиент» → через 2 секунды кот порадуется, а статус сменится на approved

# Умный кредитный кабинет предпринимателя

Сквозной цифровой кредитный конвейер для МСП: клиент подаёт заявку, система считает риски (правила + OCR + LLM), банк выносит решение.

## Стек
- Frontend: React + Vite
- Backend: FastAPI + SQLAlchemy
- БД: PostgreSQL
- ИИ: Ollama (Qwen 2.5 1.5B, open-source) + Tesseract OCR
- Всё в Docker

## Запуск
```bash
docker-compose up --build

Первый запуск занимает 5–10 минут (скачиваются образы).

После старта выполните один раз (загрузка LLM в контейнер Ollama):
docker exec -it smart-credit-cabinet-ollama-1 ollama pull qwen2.5:1.5b

Откройте:

Клиент: http://localhost:3000/client

Банк: http://localhost:3000/bank

Swagger: http://localhost:8000/docs

Проверка ИИ
Используется модель Qwen 2.5 1.5B через Ollama. Если Ollama недоступна, система автоматически переключается на rule-based fallback — сквозной сценарий остаётся работоспособным.

Демо-сценарий
Клиент вводит данные → получает рекомендации.

Нажимает «Оформить» → заявка уходит в БД.

Переключаемся в «Банк» → запускаем проверки → одобряем.

Возвращаемся к клиенту → кот радуется, статус «approved».
